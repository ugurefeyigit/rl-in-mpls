\paragraph{PPO sensitivity grid (E3).} One factor at a time around the
default, on training root 42, selected on validation seeds only: learning rate
$\{10^{-4},10^{-3}\}$; rollout length per environment 2048 (batch 1024);
entropy coefficient $\{0, 0.03\}$; clip range $0.1$; and, added after the
return decomposition because they target the proposed mechanism (noisy
advantages hiding small immediate costs) while keeping $\gamma=0.995$, reward
normalization (running return scale, observations untouched) and GAE
$\lambda=0.8$. Two planned variations (rollout 128, network $[64,64]$) were
dropped for compute before they ran. The discount is varied separately (E2,
$\gamma\in\{0,0.9\}$). The configuration with the best validation return is
retrained on two further roots (E3b) and compared with the default on the same
roots.
