\begin{abstract}
Reinforcement learning (RL) is increasingly applied to traffic engineering
(TE), but whether TE decisions are sequential enough to need it is rarely
measured. We study incremental MPLS-TE in which routing state persists, one
label-switched path may move per five-minute interval, moves are costly and
followed by a hold-down, and an action mask enforces failures and
protected-class capacity---formally a Markov decision process. On a
flow-level 18-router backbone, a masked contextual bandit that regresses only
the immediate reward beats MaskablePPO on all \TestBanditRoots{} training
roots (paired return difference \Gap; $t$-interval over roots [\GapTLo,
\GapTHi]); a PPO configuration tuned on one root does not change this on four
fresh roots. Varying the discount within each learner family points to the
horizon rather than the algorithm: return falls as $\gamma$ grows for PPO and,
beyond $\gamma=0.5$, for a bootstrapped Q-learner; long-horizon PPO oscillates at hold-down
expiry. A clairvoyant planner that re-plans every interval but assumes no further
change gains little from looking beyond the next interval, yet rollouts in
which a greedy controller reacts afterwards show that first moves do shape
later value; the learners did not exploit this. Neither learner is the best controller: a
per-interval min-max-utilization MILP whose two parameters are chosen on
validation seeds beats both. When a move's effect is delayed by one interval,
the bandit fails by construction and falls below PPO, while the MILP stays
ahead of every learner; a simulator-only rollout diagnostic, run without any
training, flags this regime. A prior internal study's bandit result reproduces on
a different software stack; its PPO result does not. Persistent state alone
did not make a planning horizon useful for the learners we trained, and
simple rollout measurements, cheap to run before training, help decide
whether a sequential learner is warranted.
\end{abstract}
