\section{Conclusion}
\label{sec:conclusion}

For an incremental, masked MPLS traffic-engineering problem with persistent
routing state, a masked contextual bandit beats MaskablePPO on every training
root and reaches the return of an untuned per-interval MILP optimizer; a
validation-tuned version of that optimizer is better than both learners of
the main comparison. Varying the
discount within each learner family points to the planning horizon rather than
the learning algorithm: PPO with $\gamma=0$ is not detectably different from the bandit at three roots, PPO with
$\gamma=0.995$ settles into costly oscillations on most roots, and a
bootstrapped value learner does not improve on the bandit. A clairvoyant planner
that re-plans every interval but scores each move as if nothing changed
afterwards gains little from looking beyond the next interval, and with traffic
held fixed the first interval's reward already ranks moves almost as such a
24-interval criterion does. These are statements about planners with a
no-change continuation, not upper bounds on the value of lookahead. Once a move's effect is delayed, a learner of the decision-time reward
fails, and the same simulator rollouts that showed little to plan for in the
base environment show it clearly there. A sequential learner should therefore be justified by measured temporal
coupling---delayed effects, or exogenous dynamics that the controller can
predict---rather than assumed from the fact that the problem is formally an
MDP.
